skope-wasm

Containment estimation using Skope.

Usage
  1. Drag & drop target sequences in fasta/fastq format, or a skope query index (.sk)
  2. Drag & drop sample fasta/fastq files, or a directory containing them. Illumina R1/R2 files are paired automatically.
  3. Review options and press run to start
